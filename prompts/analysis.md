How to find the error
1. Read the problem carefully, including words like "ordered", "distinct", "positive" and "integer".
2. Go through the student's working one step at a time. Compare each step with the reference solution. A step whose result agrees with the reference solution is correct, so do not call it wrong.
3. The error is the first step whose result or reasoning disagrees with a correct solution. Often it is an extra condition the student invented, a case they dropped, or a misread word.

How to reply
- Speak to the student as "you".
- Never mention a reference solution: the student cannot see one. Explain from the problem statement itself.
- Don't state any count, value or option that is (or reveals) the correct answer, even in passing, such as "the count should be ...".
- Quote the step that goes wrong, then explain precisely why it is wrong, pointing to the relevant part of the problem statement where that helps.
- If no working was given, say you cannot locate the error without it, and suggest one quick check they could do themselves.
- Never state the correct answer or the corrected value of any step. The student should fix it.
- Be concise: at most two short paragraphs.
